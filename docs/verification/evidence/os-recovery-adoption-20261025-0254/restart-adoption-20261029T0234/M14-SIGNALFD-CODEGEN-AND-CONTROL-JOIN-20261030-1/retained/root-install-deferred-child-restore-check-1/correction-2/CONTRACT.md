# Bounded restore probe correction

Functional McKernel OS/apps and Rust/assembly migration only; no security testing. This successor preserves the original probe and applies the independent review corrections. No test, fork, root operation, external signal or cleanup has run.

After the exact pinned production `DeferredFork.fork_and_pin` returns or raises, the owner recovers only its actual child record. While the child remains gated, `verify_pin` checks the observed child birth and direct parent twice, the kernel `anon_inode:[pidfd]` type, `FD_CLOEXEC`, and fdinfo's exact PID. Before reading the child event or sending GO, the parent writes and fsyncs a bounded `DEFERRED_RESTORE_CHILD_CUSTODY_V1` JSONL record to the existing regular stdout capture with actual PID, birth, pin-verification state and any guard/pin error class/errno. A publication failure is UNKNOWN; it does not permit GO or a retry of that output.

GO requires a verified pin, a successful guard, a successfully published early record and an exact child callback record matching actual PID, parent PID, restored signal mask and handlers. Otherwise the parent closes only its own gate writer once so the waiting child can observe EOF, then observes its known child. The pidfd is closed exactly once only after positive pidfd terminal observation and a successful direct terminal wait. A missing or uncertain pin, terminal/wait proof, close or output leaves actual unproved handles and owner retained in UNKNOWN; the probe emits at most one separate bounded stderr diagnostic and holds rather than silently exiting. It never sends a signal to another PID or process group.

The existing outer owner must reserve and monitor the exact process tree, record early output before the external deadline, and reconcile any live child/parent/uncertain handle if the foreground timeout terminates the probe. Neither that timeout nor a model transition proves teardown. The retained 4 GiB UNKNOWN install reservation and all native resources remain unchanged.

`test_gates.py` supplies six mocked source-only cases for verified-pin/publication gating, strict event identity, no premature pidfd close, positive terminal/wait close, and short early-output no retry. The real probe and tests are unrun. Root must separately review the exact command/profile, then grant its actual one-shot only after live controls, resource, weekly and inherited clock checks. The supplied argv assumes fresh `source-test-runs/restore-probe-0002` and its private TMPDIR; no directory was created by this packet.

This separate successor also closes the child's inherited gate-writer FD exactly once before the callback report. Therefore a parent-side gate-writer close actually produces EOF when GO is withheld. A close exception is reported by the existing child callback error path and is never retried. The prior correction remains preserved and must not be executed.
