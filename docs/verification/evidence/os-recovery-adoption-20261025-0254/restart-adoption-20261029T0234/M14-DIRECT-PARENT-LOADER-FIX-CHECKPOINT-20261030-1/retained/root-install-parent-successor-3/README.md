ancestor once after opening its next nofollow component. It retains the actual
review, child-entry and parent-source leaf descriptors and verifies the same
hashes before executing their exact bytes. Configured stop signals and SIGALRM
are deferred across open-to-record and close disposition. A close error marks
CLOSURE_UNKNOWN, removes the possibly closed numeric FD from the live record,
and propagates without retry. An open failure retains the previously owned
ancestor. No operation lease, source leaf or process pidfd is closed here.
