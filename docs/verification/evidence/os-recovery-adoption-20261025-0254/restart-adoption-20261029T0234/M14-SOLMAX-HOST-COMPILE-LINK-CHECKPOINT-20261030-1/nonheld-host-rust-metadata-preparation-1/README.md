## Staging failure and bounded correction

The first private overlay copy failed with `PermissionError [Errno 13]` writing `src/kernel/rust/syscall_policy.rs` because the retained read-only snapshot copied its owner-only mode. Inspection showed UID/GID 1000, both private staged file and parent owned by holden, file mode `-r--------`, parent `dr-x------`, owner-only file ACL and a read-write ext4 mount. Only those two private staged paths received `chmod u+w`; the source-only copy then succeeded. No shared source, lock, evidence or ownership changed. This was a filesystem staging failure, not a compiler failure; no test or compiler was invoked.

The result can only inform candidate type repair. A successful host metadata check would not establish selected default/production build, actual C ABI/link ownership, app behavior, native operation, C retirement or M14 acceptance.
