Frozen CURRENT119 `do_mmap` invokes `xpmem_update_process_page_table` when the object has MF_XPMEM, with no ENABLE_XPMEM preprocessor guard. The retained 119 link map contains the public update symbol and Rust body. Their mere presence is not a native call result. `vm_range` in process.h has no refcount; XPMEM references attachment/access-permit/segment/thread-group objects, not the mapping node. Update writes `att->at_vmr`, so copying scalars or checking a pointer after a writer/reader gap does not establish the same live range.

Actual update -> `xpmem_fault_range_page_in_bridge` -> `xpmem_fault_process_memory_range_inner` -> body -> `xpmem_ensure_valid_page_bridge` -> `xpmem_pin_page_bridge` -> body. For remote source VM pin takes its range reader, releasing it before its missing-stack fault; for same VM it skips that acquisition. Missing stack invokes `page_fault_process_vm`, whose `process_do_page_fault_vm_body_impl` can acquire that VM's writer to expand the stack unless `is_memory_range_lock_taken` matches CPU. The outer mmap XPMEM call holds current VM reader, and the code shown does not establish that this exception applies. Thus same-VM missing-stack may self-deadlock even with the proposed atomic downgrade. Review actual attachment constraints and fault provider ordering; do not treat the downgrade as sufficient. Update's other branch `xpmem_fault_map_present_page` takes remote segment VM reader while current reader remains held; cross-VM order and page-table/fault callbacks also remain to be reviewed.

`downgrade-proposal.PRIVATE.rs.inc` is a concrete conditional source repair: it calls an intentionally undefined lock-owner primitive to transition writer directly to reader and retains the normal reader unlock; early failures acquire a reader conventionally. The shared lock implementation currently exposes no such primitive. It requires owner implementation and independent memory-order, preemption and lock-order review, including the stack-fault issue above. The proposal is not selectable, compiled or native-qualified.
