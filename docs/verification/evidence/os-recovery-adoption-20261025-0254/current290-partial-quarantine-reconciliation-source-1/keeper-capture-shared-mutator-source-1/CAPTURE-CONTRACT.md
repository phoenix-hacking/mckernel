# Capture wrapper source contract

Functional McKernel OS/apps and Rust/assembly migration only; no security testing.

The callable runtime interface is `run_pipeline(packet, raw_packet, evidencePath, next_command)`. The runtime alone owns custody, phase gates, actual target checks and terminal resource release. Entry returns only after that runtime returns a terminal state; a postentry wrapper exception retains the process without signaling or silently closing custody.

The entry CLI requires `--packet`, `--packet-sha256`, `--capture-directory`, `--authorization`, `--authorization-sha256`. The outer CLI accepts packet and authorization paths and hashes; directory paths come from the exact packet. Launch authorization is a separate immutable envelope pinning both a Root grant and an independent execution release. The grant pins the entry argv prefix without authorization suffix, avoiding an impossible grant/envelope hash cycle. Outer appends the verified immutable authorization path/hash suffix. Outer validates packet SHA and entry SHA before executing any entry source bytes. All three pipeline source files must match packet path, byte size and SHA256. The three evidence directories and root-only command inbox must be precreated, identity-bound, canonical and disjoint.

The exact outer child argv is `/usr/bin/sudo -A /usr/bin/taskset -c 7 /usr/bin/prlimit --as=2147483648:2147483648 --fsize=33554432:33554432 --core=0:0 -- /home/holden/anaconda3/bin/python3.9 -I -B ENTRY --packet PACKET --packet-sha256 SHA --capture-directory ENTRY_CAPTURE --authorization AUTH --authorization-sha256 AUTH_SHA`. No preexec privilege or environment mutation occurs. Inherited askpass is used by sudo without inspection or capture.

Outer records its own direct child birth while blocked before exec, then permits execution and records a genuine direct wait4 result plus rusage. This is a JOIN of the newly launched sudo child only, never a claim of historical outer1060802 retirement or direct root1060806 JOIN. Root/sudo identity and typed current absence belong to the separately reviewed runtime adapter.

STDOUT.raw and STDERR.raw are exclusive regular files, each bounded to32MiB. The collector drains excess bytes and records overflow. A stream write failure is recorded while draining continues, allowing ordinary child completion. These outcomes fail capture acceptance. An unrecoverable postexec observer/read fault records OUTER-UNRESOLVED-CAPTURE when possible, retains its own pipe endpoints/direct wait, and never signals the keeper. That state is explicitly unresolved capture ownership; it is not retirement. If direct wait4 subsequently completes, OUTER-FAULT-DIRECT-CHILD-JOIN records that actual observation before pipe retirement. Preexec observer failure refuses execution via gate EOF and joins the refused child without signals.

18 private fixtures passed under CPU0 and AS2GiB. They test JSON/source/authorization binding, the new fixed window and three clocks, disjoint directories, one-shot inbox, current adoption operation, true child birth/JOIN/rusage, output overflow, streamwrite failure, execfailure and preexec observer failure. No actual keeper launch, productionroot read, signal, privileged action or native proof was performed. Independent source/execution review, fresh resource admission, immutable authorization and precreated evidence directories remain required before a real launch.
