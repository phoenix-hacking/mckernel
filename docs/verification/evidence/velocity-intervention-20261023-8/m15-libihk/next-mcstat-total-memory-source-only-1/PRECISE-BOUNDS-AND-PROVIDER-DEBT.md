Functional McKernel OS/apps and Rust/assembly migration only; no security testing.

Total/free public APIs and actual sysfs/parser chain are now Rust source, not a wrapper calling the C chain. The existing accepted Rust ihkconfig mem_parse/mem_array bodies are reused byte-for-byte; sysfs uses the same libc getline/sscanf/snprintf semantics and the original eprintf policy. Parser failure return is intentionally ignored by the public query, just as C, so early allocation failure may still lead to zero/partial outputs. No repair is hidden in this parity source.

The actual public C stack buffer is 16*1024 bytes and the parsed chunk array is 1024 entries. Complete, untruncated defined-domain output requires sum(decimal_bytes(free_kb*1024 mod ULONG)+1+decimal_bytes(node))+comma_bytes+NUL <=16384, and parsed chunk count <=1024. Each later snprintf must still receive a pointer within the caller buffer and nonnegative remaining size. A single final truncation is defined and included in source vectors; a subsequent write after an earlier would-have-written len exceeded the buffer is existing C undefined behavior and cannot earn equivalence. Multiple matching lines per node and a missing node gap preserve the original odd output, rather than inventing a new format. Actual supported guest meminfo bounds/native output remain unqualified until real evidence; no filesystem inventory or live query was made.

Host provider issue is concrete: /usr/include/x86_64-linux-gnu/sys/stat.h optimized stat calls __xstat(_STAT_VER), bits/stat.h selects version1 on x86_64; current libc exports __xstat and no plain stat. The Rust source therefore requires exact build data ihklib_stat_abi_xstat1 for this host, or separately proven ihklib_stat_abi_stat for a different actual target. Neither/default/both selection refuses compilation. 144B/alignment8 stat storage is explicitly compared to actual C sizeof/align in the future fragment. Pinned Rocky GCC14/BFD2.41 libc/header closure is not available from this host check; its stat ABI remains NULL. No C runtime shim or invented provider added.

Source fragments have no main, build command or resource reservation. Root's existing production queue79d138 remains the single executable-ready queue. The prior globals/config/remaining C debt and balanced-memory leaks/OS listing race remain preserved.
