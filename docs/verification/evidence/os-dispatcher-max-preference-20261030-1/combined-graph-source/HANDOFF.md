No original validator, driver, collector, source-binding/effective-view refusal, controller or evidence was edited. No source was selected, mounted, built, executed or accepted.

`parse_candidate_data(bytes)` parses strict records into frozen typed DATA. It rejects duplicate JSON keys, null fields, malformed integer identities, target/order/access differences, host/inode aliases, incomplete/inconsistent directory ancestry, known file path/hash differences, parent mount mismatches, incomplete pre-shadow membership and differing effective child identities. Directory content and snapshot/view digests are supervisor statements; this parser does not observe their contents or authenticate them. Matching declared identities cannot prove no actual filesystem aliases exist. The result always has `authority=None` and status `UNAUTHENTICATED_CANDIDATE_DATA_ONLY`, regardless of its synthetic tag. There is no execution/admission API.

`SYNTHETIC-FIXTURE-NOT-A-RECEIPT.json` and all test inputs use invented identities, custody and mount facts. They are synthetic DATA and must never enter a production receipt channel. The tag-mutation unit case specifically proves removing the tag supplies no authority.
