# First prepublication fault contract, version 1

This contract is frozen from source before executing the first fault guest. It
applies only to `prepublish-hard` with the unchanged Rust-enabled launcher,
ordinary `read(0, buffer, 16)`, sixteen input bytes `0xa5`, the module-3 owner /
phase / transport overlays, and one immutable selected response claim.
[The comparison input](../../scripts/application-tests/contracts/stability-prepublish-hard-20260913-v1.json)
has SHA-256 `025ffc1bb8722c321912169825ef7c4ff0dc452c9f14dd8f82667778a29cc665`.
Its exact existing `owner_observations.validate_run` schema has no provenance
fields; the accompanying [source-binding record](stability-prepublish-hard-contract-20260913.json)
binds this derivation, retained compiler inputs, modules and launcher separately.
No guest result or synthetic counter fixture supplied these expectations.

The actual launcher returns **value 16 with a zero-length RET copy descriptor**.
The retained Rust dispatch defaults syscall 0 to `act_generic_syscall`
(`executer/user/rust/mcexec_helpers.rs:2859`). That function calls the actual
generic syscall bridge, then `do_syscall_return(fd, cpu, ret, 0, 0, 0, 0)`
(lines 1662–1668). The C bridge issues `syscall(number, args[0..5])` directly
(`executer/user/mcexec.c:5670`); Linux read writes the launcher mapping. The
Rust return helper preserves zero `src`, `dest` and `size` in its descriptor
(lines 1016–1043). This is distinct from the optional 16-byte RET copy path.
The exact retained launcher sources are byte-identical to these repository
sources; retained compiler flags enable `MCEXEC_RUST_HELPERS`.

In the compiled module-3 source, `mcctrl_process.rs:324` skips user-buffer copy
when descriptor length is zero, and `smp_application.rs:966` returns from its
copy closure before invoking the copy callback. Even a nonzero optional RET
copy would call `Memory::application_copy` through `smp_service.rs:906–916`,
which is separate from `SyscallResponse::pager_copy`. The only payload counter
hook is in the latter method (`staged-source/sysfs_memory.rs:601`, generated by
`scripts/tests/prepare_stability_owner_observer.py:80–82`). It counts accesses
to the exact selected response claim, not all image or Linux MM writes.
Consequently the selected pager payload counters remain zero; that does not
claim that no application bytes were copied or that the sixteen input bytes
were independently verified in guest memory.

Response construction calls `ResponseMemory::address` before the healthy
Delivered read is selected. The observer's counters match only a fully
published immutable selection (`stability_observer.rs:203–269`), so the
construction access is outside this counter epoch. `Response::prepare`
acquires the address once, writes servicing TID/result and changes wake state
from 2 to 1 (`host-kernel/native-rust/application_syscall.rs:400–431`). The
selected hard-fault send returns `-5` before invoking the real publisher
(`scripts/tests/fixtures/stability-transport-fault/send.append.rs:95–99`).
`Completion::publish` therefore stops at `send(packet)?`, before its second
address acquisition, status publication and release (production lines
442–463). Transport quarantine preserves the unfinished call and claim
(`smp_application.rs:591–658`, `smp_application_syscall.rs:601–617`). Metadata
snapshots do not call these access hooks. AcceptedReturn, Terminal and the
five-second comparison consequently retain address count one and no releases.

The frozen actual native RET observation is `errno=-71`, `accepted=1`,
`value=16`, with elapsed time at most 15,000,000,000 ns. Successful prepare sets
the accepted output before waiting; quarantine makes that already accepted
wait return `EPROTO` (`smp_application.rs:934–991`). The verification-only hook
records the actual invoke result and accepted output, before `result?`
propagates to the launcher (`prepare_stability_transport_fault.py:99–107`).
This RET errno is distinct from the original transport fault and subsequent
new-admission `EIO`. The time bound is a required runtime observation, not a
source proof that scheduling will meet it.

The unchanged launcher can exit naturally with status **0** after the terminal
RET error. Rust `do_syscall_return` prints `perror("ret")` and returns; it does
not terminate the process. The next WAIT encounters terminal state and returns
a non-EINTR error (`smp_application.rs:697–725`). Rust
`act_main_loop_body` then returns 1 to the worker's `td.ret`
(`mcexec_helpers.rs:2911–2985`). `mcexec_join_all_threads_body` joins workers
without aggregating those values (3013–3035); `mcexec_finish_main_image_body`
returns 0 after joins (2374–2411), and the Rust main / C main wrappers propagate
that 0 (4011 / `mcexec.c:4633–4635`). Thus launcher exit 0 is compatible with
an uncompleted guest syscall. It must never be interpreted as payload exit 0,
payload success, normal McKernel cleanup, or quarantine proof.

The controller retains the launcher with `WNOWAIT`; its own cleanup can send
SIGKILL if Linux termination has not completed (`owner-phase-v1/controller.c:670–726`).
The final reviewer must classify the **actual** raw wait: natural exited/0 is
source-compatible, and signaled/SIGKILL requires the retained owned-cleanup
attempt and raw signal evidence. A recorded kill attempt can race with natural
exit, so it does not prescribe the raw wait. Other terminal exit/signal values
require first-failure review. No natural exit, SIGKILL, or deadline is fabricated
from this source trace; libc/kernel exit completion and the controller's
observed ordering remain runtime evidence.

The comparison still requires exact original worker/delivery/response/ledger
identity, actual phase timing, stable Terminal/+5 inventories and counters,
preserved response bytes against the accepted prefix, real ring packet binding,
actual RET entry/leave records, source and image provenance, complete controller
artifacts and final export acknowledgment. This source contract and a matching
counter comparison grant no application, transport, runtime-release or OS
acceptance. Existing synthetic parser fixtures remain unchanged.
