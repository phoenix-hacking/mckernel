How to read this number
------------------------------------------------------------

This is a functional-area estimate, not a strict line-count. The Rust build
foundation and first shared primitives are in place, but most high-risk kernel
subsystems remain C. A conservative mechanical LOC baseline is available with
`scripts/rust-ownership-report.py` and is currently much lower than the
functional dashboard because mixed C wrapper files still count as C debt.
