How to read this number
------------------------------------------------------------

This is a functional-area estimate, not a strict line-count. For this goal, the
functional dashboard is the progress score: core categories need to reach 100%
with verified Rust-owned behavior. The mechanical LOC report is retained only
as a C-debt inventory and sanity check; it does not measure whether the port is
functionally close to done.
