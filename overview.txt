McKernel Rust Migration Overview
Updated: 2026-05-18

Overall Rust ownership estimate: 5%

How to read this number
------------------------------------------------------------

This is a functional-area estimate, not a strict line-count. The Rust build
foundation and first shared primitives are in place, but most high-risk kernel
subsystems remain C. A later tracking phase can add an automated line-count and
symbol ownership report.

Current completed Rust-owned behavior
------------------------------------------------------------

- Freestanding no_std Rust kernel crate exists under kernel/rust/.
- Rust can be linked into the x86_64 mckernel.img path.
- C fallback builds remain part of the migration contract.
- Rust exports C ABI replacements for the first rbtree, llist, and bitmap
  routines.
- Rust now owns bitmap_find_next_zero_area(), bitmap_find_free_region(),
  bitmap_allocate_region(), and bitmap_release_region() when
  ENABLE_RUST_KERNEL is on, while the C implementations remain available for
  fallback builds.
- Rust now owns the first page-allocator rbtree helper cluster
  `__page_alloc_rbtree_free_range()` and
  `__page_alloc_rbtree_alloc_pages()` when ENABLE_RUST_KERNEL is on, while the
  C helper implementations remain available for fallback builds.
- Rust now owns the generic bitmap-backed page allocator no-lock helper
  cluster when ENABLE_RUST_KERNEL is on:
  `__ihk_pagealloc_large_nolock()`, `__ihk_pagealloc_alloc_nolock()`,
  `__ihk_pagealloc_reserve_nolock()`, `__ihk_pagealloc_free_nolock()`,
  `__ihk_pagealloc_count_nolock()`, and
  `__ihk_pagealloc_query_free_nolock()`. The exported C page allocator API and
  MCS lock/IRQ handling remain in C wrappers, and C fallback builds still use
  the original C implementation.
- Rust now owns the no-lock zero-free helper
  `__ihk_pagealloc_zero_free_pages_nolock()` behind the C exported
  `__ihk_pagealloc_zero_free_pages()` lock/log wrapper.
- Rust now owns the rbtree reserve/get-root helper pair:
  `__page_alloc_rbtree_reserve_pages()` and
  `__page_alloc_rbtree_get_root_chunk()`.
- Rust now owns the `__ihk_numa_add_free_pages()` helper body behind the
  exported C logging wrapper, including incoming range zeroing, rbtree
  insertion, min/max tracking, and free-page accounting.
- Rust now owns the single-node deferred-zero helper
  `__ihk_numa_zero_free_pages_node()` while the C wrapper still owns the
  all-node traversal and zero-at-free policy check.
- Rust now owns the under-lock NUMA allocation body
  `__ihk_numa_alloc_pages_nolock()` while the exported C
  `ihk_numa_alloc_pages()` wrapper still owns the CPU-local-cache precheck,
  MCS lock/unlock, and debug logging.
- Initial ABI/layout checks exist for shared structures.
- Primitive and allocator-helper equivalence testing exists in
  kernel/rust/tests/run_equivalence.sh.

  `setsid`-based watchdog instead of relying on GNU `timeout`, because a stuck
  kernel ioctl can prevent `timeout` from returning cleanly.

  previous `/dev/mcos0` OS instance. The validation script now runs
  `mcstop+release.sh -k` before boot-smoke and during watchdog cleanup so stale

Recommended verification style
------------------------------------------------------------

Run the ladder from plan.txt in order:

V0: Documentation integrity
V1: Source inventory
V2: Rust object only
V3: Rust primitive equivalence
V4: Rust-enabled kernel image
V5: C fallback kernel image
V6: User-space tools
V7: Host modules compile
V8: Module load only
V9: McKernel boot only
V10: Minimal user workloads
V11: Focused regression tests
V12: Phase-specific stress

Stop on the first failing step. Record the failing command, environment, and
error summary in kernel.log before making more changes.
